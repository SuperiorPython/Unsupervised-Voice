# README row template

Copy the line below and paste it directly under the table's header row (newest video on top).
Fill in the number and idea, then change `no` to `yes` as each step is done.
When the video is live, put the YouTube link in the last column. The weekly report reads that link.

```
| 002 | [Idea title](videos/02-short-name.md) | no | no | no | no |  |
```

Columns: `#` | `Idea` | `Script generated` | `Voiceover` | `Animation` | `Released` | `Links`

- **Script generated**: the talking-points file for this video is filled in (`templates/talking-points.md`).
- **Voiceover**: the final voice recording is done.
- **Animation**: the video is rendered.
- **Released**: it is public on YouTube.
- **Links**: the YouTube URL once released, for example `[watch](https://youtu.be/XXXXXXXXXXX)`. Leave blank until then.
